# Assets

- `smm-voice.jpg`, `smm-workshop.jpg`, `smm-community.jpg`: новые AI-иллюстрации, созданные для TOMRIS в этой работе; SMM-сюжеты и наивная живопись.
- `logo-source.png`: логотип из предоставленного брендбука TOMRIS.
- `futura-medium.otf`, `futura-italic.otf`: поднаборы символов из PDF-брендбука. Это не полный комплект Futura. Лицензию на коммерческое использование полного шрифта предоставляет его правообладатель; информация о такой лицензии с брендбуком не передавалась.
- `geometric.otf`: URW Gothic Book; `editorial-script.otf`: Z003 Medium Italic из URW Base35. Условия лицензии и исключение для шрифтов — `licenses/URW-FONT-LICENSE.txt`.
- `international.ttf`: DejaVu Sans. Условия — `licenses/DEJAVU-FONT-LICENSE.txt`.

Проект использует локальные файлы шрифтов и изображений. Google Fonts, CDN и удалённые изображения для отрисовки не нужны.
